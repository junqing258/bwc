# 筑材智算｜项目设计提示词

本文可直接交给产品设计、网站生成或开发 AI 使用。默认面向中国市场，采用简体中文、人民币和公制单位。

## 完整提示词

你是一支由建筑算量专家、建材采购专家、B2B 产品经理、UX/UI 设计师和全栈工程师组成的团队。请设计并实现一个中文建筑材料算量与交易平台，项目名称为“筑材智算”。

### 一、产品定位

面向建筑承包商、造价人员、设计工作室、采购人员和建材供应商，提供完整流程：

创建项目 → 上传建筑模型 → 检查模型质量 → 确认构件及材料 → 计算材料用量 → 估算采购预算和施工费用 → 生成采购清单 → 供应商询价与比价。

第一阶段聚焦混凝土、围栏/护栏、屋面材料及其构造层。

核心价值：让用户从建筑模型得到可追溯、可修改、可采购的材料清单，理解每项数量和价格的依据。不要只制作宣传首页，重点实现可操作的项目工作台。

### 二、产品边界

必须分别保存和展示：模型几何数量、按计量规则得到的工程量、考虑损耗搭接及包装后的采购量、材料采购预算、包含人工机械运输安装等费用的施工估算。

AI 用于识别建议、材料映射、异常解释和操作辅助。最终数值由确定性的几何计算、规则和已确认参数生成，不得让语言模型凭外观编造工程量。

不承诺所有模型自动识别。信息不足时列出待补参数、受影响项目和下一步操作。未知数量和未知价格不能显示为 0。

### 三、文件导入

设计三种入口：

1. 三维模型：第一阶段优先支持 GLB/glTF、FBX、OBJ；IFC 作为具备建筑语义的独立导入路径。每种格式标明实际支持状态和限制。
2. 3ds Max 原生文件：识别 .max；没有真实转换能力时展示导出 FBX/OBJ 的引导。可保留提交原文件转换入口，但必须标识未接入状态，不得假装浏览器已经解析 MAX。后续独立转换服务需验证版本、插件依赖、运行环境与授权。
3. 图片辅助估算：支持 JPG/PNG 效果图，要求补充已知尺寸、厚度、坡度和构造。与三维模型算量分开，结果标识为参数估算。

导入后检查单位与比例、坐标方向、对象变换、对象数量、模型范围、重复对象、实例、相交、网格封闭性、缺失材质、外部引用以及类别和材料信息。

单位未知时要求用户确认单位或用已知长度校准；修改单位后重新计算长度、面积和体积。

原始文件、浏览用轻量模型、计算用几何数据分别保存。展示模型的简化不得改变算量结果。

### 四、用户角色与权限

- 项目负责人：创建项目、邀请成员、管理预算、确认清单。
- 算量人员：分类构件、补充参数、调整规则、复核结果。
- 采购人员：商品选型、生成询价、比较报价。
- 供应商：维护商品、提交报价、填写供货和交付条件。
- 管理员：管理材料分类、规则版本、供应商和价格来源。

供应商默认只看到授权分享的询价信息。分享完整模型需要单独授权。

### 五、页面结构

1. 首页：产品价值、三类材料场景、操作流程；主要按钮为创建项目、体验演示项目。
2. 项目列表：搜索、状态筛选、最近更新排序；卡片展示地点、模型版本、负责人和待复核数量；预算未完成时显示待完善。
3. 新建项目：名称、地点、用途、币种、单位、估算范围、价格日期、计量规则。
4. 导入与检查：真实上传、转换、解析和检查状态；列出错误、警告及修复建议。
5. 算量工作台：左侧楼栋/楼层/构件树和混凝土/围栏/屋面分类，支持已确认、待确认、无法计算筛选；中间最大区域为三维模型，支持旋转、缩放、平移、选中、隐藏、隔离、透明、分类着色、测距和剖切；右侧为构件属性、分类建议及依据、材料尺寸、缺失参数、公式结果、来源和复核状态；底部切换材料清单与问题清单。点击清单定位并高亮构件，点击构件同步定位清单。
6. 用量与预算：按材料、楼层、区域汇总；修改参数、查看规则、设置损耗；显示已计价小计、未计价项目和预算覆盖范围。
7. 建材选型与比价：材料清单映射到商品规格，区分完全匹配、近似替代和需要确认。
8. 询价与报价：已确认清单生成询价草稿，用户检查后提交，供应商逐项报价，支持版本和有效期。
9. 报告与版本：导出清单、预算、参数说明和问题清单；比较模型版本和工程量变化。

### 六、混凝土算量

按基础、柱、梁、板、墙、楼梯等构件汇总，记录混凝土等级、用途、供应方式等必要规格。

计算优先级：先校核模型数量属性；再采用有效实体或封闭网格计算；表面模型在用户补充厚度后做参数估算；数据不足列入待补项。

处理洞口、重复构件、实例变换、梁板柱相交、类别间重复计量及扣减。不能用对象包围盒体积代替实际体积，不能用建筑外壳包围的空间作为混凝土量，不能将非封闭网格结果悄悄当作准确工程量。

分别显示几何体积、规则调整量、净工程量、采购调整量、建议订购量。

预拌混凝土默认按 m³ 采购。没有配合比时不自动拆出水泥、砂石和水。泵送、运输、小批量和等待费用单列，检查是否已包含在报价中。

### 七、围栏算量

支持延米、平方米、片、套、根等报价单位。参数包括材质、高度、长度、板宽或标准跨距、立柱间距、门洞、转角、基础、表面处理及安装方式。

从模型或人工确认路径获得分段中心线，区分开放、闭合、门洞和独立分段。输出围栏净长度、面板数、立柱数、转角柱、端柱、门及配件、基础混凝土和安装费。

立柱数依据拓扑、门洞和共享节点计算，不能统一套用总长度除间距再加一。基础混凝土与混凝土清单关联，避免重复采购和计价。

### 八、屋面算量

分别展示水平投影面积、实际坡面面积、洞口扣减、各构造层净面积、采购面积和采购数量。

优先计算已确认屋面外表面的实际面积。不得将屋面实体顶面、底面和侧面全部相加作为铺装面积。

仅在已知水平投影面积和坡度、且符合单一平面坡面条件时使用：实际坡面面积 = 水平投影面积 / cos(坡度)。复杂屋面按面片计算。

支持面层、垫层、防水、保温、找平等构造层，每层具有独立范围、厚度、扣减和采购规则。

瓦按有效覆盖面积和片数计算；金属屋面板按有效覆盖宽度、排版和长度；卷材考虑幅宽、长度、搭接与卷数；保温板考虑厚度、包装与裁切。

不得重复计算有效覆盖尺寸已包含的搭接，不用统一损耗率处理所有材料。屋脊、檐口、天沟、泛水和收边件单独计量。

### 九、价格和费用

支持用户录入、供应商正式报价、经授权的参考价和演示数据。每条价格保存来源、地区、日期、有效期、币种、单位、材料规格、税费口径、运费口径、起订量和阶梯价格。

演示价格明确标识。没有真实接口不得展示实时市场价。

两个费用视图：

- 材料采购预算：采购量 × 对应商品单价，加未包含的物流、包装等费用。
- 施工估算：根据已配置范围加入人工、机械、泵送、安装等费用；管理费、利润和税费采用配置规则及明确基数。

报价已含费用不得再次叠加。含税与未税转换必须有明确税率和适用条件。未报价条目单列；存在未计价范围时只显示已计价小计及预算未完整。

### 十、供应商与交易

业务闭环：材料清单 → 商品匹配 → 询价草稿 → 用户提交 → 供应商报价 → 同口径比价 → 采购单草稿。

比价包括同规格单价、含税到场总价、运费及卸货、起订量、供货日期、交付范围、有效期、替代品差异。规格或计价范围不同不能直接判定最低价。过期报价明确提示。

第一阶段做到询价、报价和采购单草稿。支付、结算、物流后续扩展，不伪造支付或发货状态。

### 十一、可信与追溯

每条数量可追溯到项目、模型版本、构件 ID、材料构造、单位、几何来源、公式、规则版本、人工参数、修改人和复核时间。

两组独立状态：

- 来源：模型属性、几何计算、人工参数、图片辅助估算。
- 复核：待确认、已确认、需复核、无法计算。

识别置信度不能当作数量误差。没有验证数据不宣称准确率99%，没有统计依据不生成误差区间。修改分类、厚度、损耗或规格后重算受影响条目，标记旧报价是否失效。

计量和计价规则需版本化；中国市场实施时核对标准全文、当地适用规则及项目合同约定，由专业人员确认具体计量和扣减规则。

### 十二、架构与安全

前后端分离：前端负责三维交互、清单和报价；后端负责模型处理、规则算量、价格与权限；转换和大型计算采用异步任务。

可评估 React/Next.js、TypeScript、Three.js 或 React Three Fiber、Python 几何服务、IfcOpenShell、PostgreSQL、对象存储、任务队列。实施前核对官方文档和当前支持范围。

原生 MAX 转换为独立可插拔能力。上传文件作为不可信输入，限制类型和资源消耗、隔离转换任务、禁止执行模型内嵌脚本、限制外部引用访问，支持删除和访问授权。

转换任务支持排队、运行、成功、失败、取消、错误原因、重试；保留已完成的分类和参数配置。

### 十三、数据对象

至少包含 Project、ModelVersion、Element、MaterialDefinition、AssemblyLayer、MeasurementRule、TakeoffItem、PurchaseItem、ProductSKU、Supplier、PriceRecord、Inquiry、Quote、QuoteLine、EstimateVersion、AuditLog。

计量规则、模型、预算、报价分别版本化。历史报告保存数量、参数和价格快照，不被后续调价静默覆盖。

### 十四、视觉与交互

专业工程 SaaS，浅色背景、深灰文字、工程蓝主色，绿色确认、橙色待复核。三类材料有一致分类色，并辅以文字或图标。

桌面大屏算量优先，移动端支持清单查看、审核和报价。保证足够大的三维视口、高可读表格、明确单位和价格口径、持续可见的未完成事项。首页让用户快速进入项目或演示工作台。

### 十五、演示和验收

提供混凝土结构、围栏和坡屋面的演示项目，虚构价格和供应商明确标识。至少验证：

1. 已知尺寸实体体积正确。
2. 单位换算对长度、面积、体积均正确。
3. 非封闭构件进入补参数流程。
4. 围栏基础不重复计价。
5. 屋面坡面与投影面积区分。
6. 门洞正确影响围栏、立柱、面板数量。
7. 损耗、搭接、包装取整分别处理。
8. 缺价格显示待询价。
9. 参数修改后清单与预算一致更新。
10. 失效报价与历史快照区分。
11. 点击清单定位三维构件。
12. MAX 不支持时提供真实处理路径。

### 十六、实施与交付

先交付产品流程、页面结构、数据模型、格式支持矩阵、算量规则、验收标准。

第一阶段：演示项目、工作台、手动分类、可实现的模型导入、三类算量、手动价格、预算汇总、清单导出。

第二阶段：IFC 信息提取、质量检查、询价报价、同口径比价、版本比较。

第三阶段：验证后的 MAX 转换、高级识别、价格服务、订单协同。

每阶段明确真实功能、模拟数据、未接入服务和人工确认事项。最终交付能够走通“导入 → 确认 → 算量 → 预算 → 询价”的产品。

## 桌面设计稿补充提示词

创建四页中文桌面高保真 UI，每页一个完整应用界面，1440×900 或等比例横向画布，可编辑文本、表格、按钮、卡片为主。不要封面或介绍 PPT。

统一视觉：背景 #F5F7FA、白色卡片、文字 #172B4D、主色 #2563EB，细边框、小圆角。约200px固定导航：项目概览、模型与算量、材料预算、采购询价、版本报告；顶部项目切换、搜索、通知、头像。各页标记演示项目和演示价格。

1. 项目概览：云栖住宅，杭州，模型V03。指标：已计价小计¥186,420、混凝土128.5m³、围栏96m、屋面246m²；提示3项待报价。住宅3D轴测预览、待办、材料汇总、预算构成。
2. 模型与算量：构件树＋最大面积三维视口＋属性面板，底部清单。蓝色高亮楼板 SLAB-021：C30、6m×4m×0.15m=3.60m³，几何计算、待确认。提示缺厚度构件，展示测距、剖切、隔离工具。
3. 材料预算：采购预算/施工估算切换。材料、规格、净量、采购量、单位、单价、金额、来源、状态表；缺价显示待询价。侧栏分别配置损耗、搭接、取整；区分屋面投影213m²与坡面246m²。
4. 供应商比价：询价状态与步骤，A/B/C三家演示供应商；比较同规格含税到场价、运费、起订、交期、有效期。不同规格不参与直接最低价排序；展示逐项报价和采购单草稿按钮。
