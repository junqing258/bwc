# 二维构件识别、AI 建议与人工确认

2026-10-28。该功能在现有二维解析结果之上增加构件层，不修改原 DWG，不自动生成三维模型。

## 工作台操作

1. 打开项目，点击底部“二维构件”或图纸工具栏“构件选择”。
2. “识别全图”根据有效闭合边界、精确端点相接的直线环、门窗块实例生成待确认候选；也可先框选局部，再“识别选中范围”。图层只作为分类线索。
3. 点击列表或图中编号，联动高亮整组来源。Shift 点击可追加多个构件；黄色问号代表待确认，绿色对勾代表已确认。缩放较小时隐藏过密编号，定位单项后可查看。
4. 在核对区调整名称、类型、楼层、材料、厚度或拉伸高度，补充核对说明，再“确认构件”或“排除此候选”。类型不明确时可保留待确认。
5. 规则无法覆盖时，框选真实曲线或边界，使用“标识选中图元”创建手工候选，或“AI 辅助识别”让当前 Codex/Claude 宿主分析实际来源并提交建议。AI 候选保留待人工确认。
6. 选中已确认构件，可运行构件计数、曲线长度、净面积和参数体积。结果进入原“计量结果”页，点击明细可回到来源图元；Shift 点击构件列表或图中编号可扩大范围。

确认按钮在面板下方，底部面板可滚动。没有 AI 账号或宿主不可用时，规则识别、手工标识和人工确认仍可使用。

## 识别范围

规则版本 `bwc-components-1` 支持：

- 源 HATCH/SOLID/3DFACE 等区域边界，以及闭合多段线；图框、轴线、尺寸和文字图层被排除。未知类型的闭合轮廓保留“未分类”。
- 同一图层、同一块实例路径内的源直线，只有端点精确相接成单环时才组合；不跨缝补线，不推测未知边界。
- 门窗图层线索明确的块实例，保留相同实例路径内的零图层成员。阵列行列和嵌套路径分别标识，不能用裸 handle 合并不同实例。
- AI 使用 `component_list`、`component_recognize`、`component_suggest` 处理结构化源数据。摘要模式不发送几何；这不是对截图进行端到端视觉识别。需要详细几何时沿用用户既有资料发送设置。

尚未覆盖自动墙线配对、相交线网的语义拆分、自动楼层分配、门窗洞口关联、平立剖与详图之间的同一实体去重，以及自动提取高度等参数。候选可能属于不同图纸视图，不能把全部候选直接当作整栋楼构件总数。

## 数据和算量边界

构件记录绑定图纸快照，保存来源实例 ID、来源图层、几何用途、规则/AI/手工来源、理由和人工核对版本。图纸快照变化后旧构件不自动迁移，需要重新识别和核对。

`component_suggest` 只接受真实源实例 ID 和分类说明，几何由服务端从源数据确定，不接收模型生成的坐标。尺寸标注、文字、点位和诊断辅助预览不能作为构件边界。AI 没有“确认构件”工具；确认只在本机核对面板进行。所有确认、修改、排除、退回操作保存前后记录。

- 未确认或旧快照构件禁止进入构件算量；已确认构件之间若共用来源图元，拒绝重复确认和重复计量。
- 多段开放曲线及符号组以 `annotation_only` 表示，只能用于构件计数，不能得到面积或体积。
- 闭合边界仍需通过几何工作器的共面、拓扑及单位检查，闭合不等于有效。
- 参数体积是二维有效面积乘人工给定的均匀厚度/拉伸高度，不表示已恢复三维实体。另一个洞口候选不会自动被扣除。
- 算量保存构件核对版本；后续修改或取消确认会使对应结果失效。导出报告包含构件记录、状态及来源，范围仍为本次选择，不是全楼总量。

## 办公楼实测

原图修订与几何保持不变。在当前采用毫米单位的快照上，约 0.82 秒生成 753 个规则候选：

| 候选类型 | 数量 |
| --- | ---: |
| 柱 | 56 |
| 墙 | 109 |
| 窗 | 108 |
| 未分类闭合轮廓 | 480 |

其中 645 个为闭合边界候选，108 个为符号组候选；这些数量不是确认构件或工程量。4,268 个可用曲线/边界源图元尚未纳入候选，其中包括轴线等被规则排除的内容。办公楼未自动确认任何构件。

浏览器验证：进入二维构件、按“柱”筛选、定位单项、整组高亮、图中问号编号及核对表单。随后真实 Codex CLI 会话完成两轮调用：先对选中实例执行规则识别，再提交 AI 建议。

- 实际工具：`component_list`、`component_recognize`、`dwg_get` 等，以及 `component_suggest`。
- AI 建议：`柱-229d3（AI待核对）`，来源实例 `occ_6f3b4c55d960c953f1bd3667`，SOLID，COLUMN 图层，块实例 AAF。
- 建议理由明确楼层、材料和高度未核实；记录更新为 AI 来源、版本 2，状态仍为 pending。
- 该轮没有确认构件、推测参数或计算工程量。
