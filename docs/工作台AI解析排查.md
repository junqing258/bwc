# 在工作台中通过 AI 排查解析缺口

当前已实现“读取真实诊断 → 冻结精确对象范围 → 辅助定位 → 明确指令重解析 → 核对新版本”的对话流程。AI 使用工作台领域工具，不直接修改 DWG 或项目数据库。

## 如何使用

会话输入框上方提供“图纸概况、解析排查、定位异常、检查选中、选中净面积、重新解析”六个快捷提问。点击后填入可编辑的问题，再点击“发送”；输入框下方显示整张图纸或当前选中范围。未冻结选择时禁用选中范围提问，单位未采用时禁用净面积提问。AI 执行中或待对账时禁用快捷提交。

打开项目后，点击提示卡中的“让 AI 排查解析问题”；解析明细中也可点击“让 AI 分析本组”。按钮会发送针对当前图纸或具体诊断组的只读任务。可以继续输入：

- “为什么解析不完整？哪些问题影响当前计算？”
- “定位这 22 条异常多段线，并说明需要补充什么依据。”
- “只检查模型空间中已有曲线或区域几何的候选对象，缺项不要按零计量。”
- **“请重新解析当前图纸”**：这是明确的版本写入指令，AI 可直接调用解析器并等待任务结束。

“能否重新解析”“如果重新解析”等询问不会授权重解析。参数修改仍沿用已有候选和服务端意图校验；单位、业务分类、洞口、厚度等依据需要明确提供。几何候选筛选不能代替这些依据。

## 本次补齐的能力

1. `dwg_diagnostics` 返回快照固定的诊断组、源对象数、模型实例数、分组建议、原始数据摘要和分页成员。诊断组具有稳定标识，查询与冻结选择集都支持该标识，避免将所有 LWPOLYLINE 当成异常对象。
2. `bwc-cad-3` 为读取后退化的多段线保留源顶点，为 WIPEOUT 保留图像参考范围，为 OLE 保留框角、载荷大小和哈希。这些数据进入独立的 `diagnosticPreview`，以橙色辅助点位或参考范围显示；规范 `geometry` 仍为空。
3. 浏览器可查询、框选、选中和定位这些辅助数据。测距吸附与几何工作器继续使用规范几何；辅助范围不产生长度、面积或体积。缺项返回 null，不伪装成零。
4. AI 的 `dwg_reparse` 绑定本轮原始消息、意图、冻结修订和快照。服务端独立校验明确指令，重新读取原图、应用既有补丁、核验身份，发布新解析版本。原图与旧产物保留，旧结果失效。
5. 模型服务失败会保存并显示实际原因。历史失败轮次也可从原始错误事件恢复原因；“失败”不会被显示成任务完成。

摘要资料模式只发送诊断统计和结构摘要，原始顶点及定位坐标仍按几何资料发送策略处理。

## 当前真实图纸结果

项目为“建筑”，文件 `综合楼附房建筑_t3.dwg`。模型空间仍有 25,230 个实例，其中 25,205 个有规范表示，**25 个缺失实例现在全部具备辅助定位预览**。这不是新增 25 个可计量对象。

- 22 条多段线：当前读取结果为端点重合、bulge 非零。保留证据，独立 CAD 复核后才能决定修复方式。
- 2 个 WIPEOUT 实例：参考范围可定位，遮罩边界、遮挡与绘制顺序尚未验证。
- 1 个 OLE：框角与载荷元数据可检查，嵌入内容未解码，也不执行其中内容。
- 88 个 SPLINE 和 2 个 POLYLINE（运行类型为 PolygonMesh）源记录未在模型空间实例化，仍未适配。
- 30,104 条读取通知、17 类仍待核验；INSUNITS=0，物理单位仍未采用。独立 CAD 验收仍为 not_run。

因此解析状态继续保持 partial。AI 可以帮助判断缺口对指定任务范围的影响，并推动受支持的操作；恢复原图中无法确定的信息、增加新图元适配和验证完整文档保持，仍需要对应数据和工程实现。

## 实测记录

- 23 项 Node 测试、13 项 Python 测试、TypeScript 检查及生产构建通过。
- 工作台实际发起的只读 AI 对话已调用 `dwg_diagnostics`，按组冻结 22、2、1 个实例，并发送三组定位事件；该轮没有发布修订。
- 工作台实际发送“请重新解析当前图纸”后，AI 调用 `dwg_reparse`、等待 `job_get`，发布 `r_26eefa68be604a9997b162ccd308e6ef`，再读取新诊断。它正确汇报辅助预览从 0 到 25、几何缺口仍为 25。
- 首轮模型服务曾返回 `Selected model is at capacity`，当轮只执行三个读取工具，没有启动重解析；该失败保留在记录中。随后两轮对话实际完成，未更改用户的全局模型配置。
- 原始 DWG 和前一解析产物的文件 SHA-256 复核一致。

完整依据见 [AI 对话验收记录](evidence/ai-diagnostics-acceptance.json)。辅助定位与真实几何覆盖须分别验收；本记录不代表全部来件已解析完整。
