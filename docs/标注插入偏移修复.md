# ACadSharp 标注插入偏移修复

2026-10-28，适配器升级为 `bwc-cad-4`，底层仍使用 ACadSharp 3.8.30。

## 原因与实现

办公楼的缓存标注包含非零 `Dimension.InsertionPoint`。此前适配器统一拒绝这种情况，产生 `DIMENSION_PICTURE_COORDINATES_UNVERIFIED`。

按照 DXF group 12 的含义，这个值是标注缓存图形的 OCS 插入偏移，不能用定义点或文字中点替代。对当前支持的默认 +Z 法向量，OCS 与所属空间坐标一致：先对缓存图形添加插入偏移，再应用所属 INSERT 的变换。缓存子对象只转换生成的几何副本，避免共享缓存块的不同标注相互影响。

普通块展开与标注缓存内部的块展开共用 `InsertMatrix`，统一基点扣除、缩放、阵列间距、旋转及 OCS 处理。尺寸标注继续输出 `annotation_only`，不作为长度、面积或体积的计量依据。

非默认标注法向量和非零缓存块基点仍保留原诊断，未将未验证情况标记为已支持。字体、线型、填充效果和标注子对象颜色仍有原有显示限制。

通过工作台“使用当前适配器重新解析”生成新版本。核对全部 7,920 个实例身份不变，非标注几何不变；原图 SHA-256、业务参数、单位设置和已登记补丁保持一致。浏览器已定位恢复的 A6C 标注并检查显示。

另将相同原图经 ACadSharp 导出临时 DXF，用 ezdxf 1.4.3 的 `virtual_entities()` 交叉检查 519 个有缓存的标注源对象的直接尺寸线端点和 MTEXT 插入位置，最大坐标差为 0。ezdxf 对显式零厚度的 LINE/POINT 变换存在零向量归一化问题，参考检查中移除了这些值为零的默认厚度属性。该检查共享 ACadSharp 的 DWG 解码结果，不属于独立 CAD 的原图显示或完整保真核验。
