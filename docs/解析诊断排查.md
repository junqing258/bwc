## 发现并修正的问题

1. 未确认单位时，旧检查器把每个对象的 UNITS_UNCONFIRMED 记成轮廓失败。现场列表共有 25,244 条记录，其中 25,232 条为这类重复项。新检查器把单位作为一次范围前置检查，依赖尺寸的检查标为 not_run。
2. 多次检查历史被累加到当前列表。现在保留历史记录，默认返回最近一次已完成检查；旧记录读取时也进行分组。
3. 普通 LINE、ARC 或开放多段线不应被自动当作面积轮廓。现在先检查曲线长度与有限性，仅对闭合或已明确声明用于面积/参数体积的轮廓进行面积检查。
4. 旧页面直接渲染数万行，浏览器自动化定位已出现 Maximum call stack size exceeded。现在按原因分组，每页最多 50 行；本图重新检查后呈现 9 组检查状态，其中 3 组需要处理，而非数万条“几何失败”。
5. 解析明细原来仅展示截断的 JSON。现在分别统计诊断记录、不同源对象、模型实例、布局实例和未展开源对象，合并重复通知，并提供同类对象查询入口。全文件检查的空定位范围显示“文件级 / 范围待核验”，不显示为影响零对象。
6. 点击顶部解析提示直接打开覆盖明细，不再隐式触发全图几何检查。检查仍通过明确的“运行检查”按钮发起。

## 第二阶段：图元适配与版本化重解析

适配器 `bwc-cad-2` 继续使用固定版本 ACadSharp 3.8.30，增加以下规范表示：

- HATCH：读取多段线（含 bulge）、直线、圆弧和椭圆边界，转换 OCS/高程至 WCS，保留岛屿样式和原生填充信息。浏览器显示边界，暂不复现填充图案、实心着色或渐变。
- DIMENSION：读取默认坐标条件下的原生缓存显示块，展开箭头 INSERT，保持父尺寸标注的实例身份。非默认法向、克隆插入点或非零显示块基点仍拒绝推测。尺寸标注为 annotation_only，标注数字和人工文字覆盖值不进入长度、面积或体积计算。
- SOLID（二维面）、3DFACE：读取边界；面积仍必须通过闭合、共面和拓扑检查，非平面面不会自动得到面积。POINT 只提供点位显示和查询，不产生长度。
- 退化多段线：保留原始顶点、bulge、宽度等信息。完全重合的端点无法确定非零 bulge 圆弧的半径，继续报告 GEOMETRY_INVALID，不虚构圆、不计为零，也不重复归类为“尚未适配”。
