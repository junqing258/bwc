## 宿主 spike 与安装

目标固定为本机 Codex CLI 0.165.0、macOS arm64、本地 marketplace 安装。按官方 [打包文档](https://developers.openai.com/plugins/build/plugins) 采用根目录清单；安装实验确认 stdio 路径变量须使用 `${PLUGIN_ROOT}`，`${CLAUDE_PLUGIN_ROOT}` 在此 MCP 配置中未正确展开，已修正。没有维护两套清单。

实际执行 marketplace add、plugin add、plugin/read、skills/list 与 mcpServerStatus/list，确认插件 Skill 可见且 31 个工具无启动错误。记录：[plugin-host-spike.json](../evidence/plugin-host-spike.json)。工具实际调用、进程退出/重新连接通过独立 MCP SDK 客户端测试，无模型推理任务。

宿主 spike 在代码实施期间补做，并非在开始编码前完成。没有验证 Codex 宿主强制退出后 detached 子进程一定存活，因此默认 MCP **不自动启动运行时**；采用用户在独立终端显式 `runtime start` 的发行方式。已验证普通 MCP 断开后领域任务继续及客户端重连；这不等同于宿主进程清理策略验证。BWC_RUNTIME_AUTOSTART 只作为显式开发开关。

安装验证使用的插件/marketplace 为临时测试安装，验证后移除，不修改用户的其他插件。清单与可安装产物保留在仓库 release 目录中。

## v0.3 继续实施：覆盖审阅与多图汇总

- `coverage.ts` 将候选归属与目标范围分开：冻结来源、按源实例保留未归属/排除/重复状态、保留无位置解析缺口、独立人工证据与参考清单。排除成员可展开并可撤回，任何改变都会升级内容指纹/版本；所有候选确认不会自动生成覆盖完成。
- 覆盖状态为 unknown / incomplete / reviewed_complete。楼层/视图未知、来源未归属、候选待核对、构件跨界、重叠归属、完全相同边界、解析缺口与依赖未决都会阻止完成；新增或修改候选、切换图纸修订会使旧结论失效。
- `scope-takeoff.ts` 按输入清单启动持久单图子任务，分别计算 calculationComplete、scopeCoverage 与 scopeComplete，固定覆盖版本和审阅 ID。旧结果不会因补审自动升级。导出保留冻结覆盖、原图或参考清单证据、当前有效性、来源指纹与逐项 CSV。
- Web 增加独立覆盖面板：源实例定位、分页、带理由和依据的批量排除、排除成员展开、参与图纸切换、无法定位缺口提示与独立覆盖结论。MCP 不提供覆盖人工提交工具。
- 已有候选洞口但尚无扣减关系时，面积/体积汇总保持 OPENING_RELATIONS_UNVERIFIED。相同边界仅作为疑似重复提示，不把几何一致性当作实际构件身份。
- 新增受控测试：故意漏识别、全候选确认但覆盖未知、无依据/越界排除、未归属来源、未知楼层、无位置解析缺口、人工补充与结论失效、同边界疑似重复、明确来源子集、重启恢复、缺计量参数和未关联洞口，以及多图导出证据。真实建筑参考答案仍未到位，不宣称 P2 业务验收完成。

本轮 v0.3 回归与发行验证记录随下列命令结果更新：`npm run check`、`npm run build:plugin`、`scripts/plugin-probe.ts` 和 `scripts/plugin-release-smoke.mjs`。

v0.3 最终回归：50 项 Node 测试、13 项 Python 几何测试、TypeScript 与生产构建通过。完全相同边界的疑似重复构件保留为未计算项，不静默合并，也不计入已知小计。覆盖完整性尚未通过时，多图任务状态保持 partial，不能因已确认子集算齐而显示 succeeded。

本机重新执行 marketplace add 与 plugin add 成功，bwc-workspace@bwc-local 0.3.0 已安装并保留。Codex 实际发现 Skill 及 36 个 MCP 工具，toolsError 为 null。桌面端需刷新插件列表以读取最新安装状态。此次应用户“重试”请求保留安装，区别于此前验收结束时的临时卸载。

## v0.4.0 Codex 会话原生填写确认

按“填写确认操作尽量在 Codex 会话界面实现”接入 MCP form elicitation。新增 review_in_session 工具，支持单位与依据、单个候选属性/核对状态、当前快照资料授权、独立覆盖结论/参考定位。模型只能指定操作和目标，无法把 userConfirmed 或模型转述的答案作为正式确认。需要看图、批量核对、来源排除继续使用 Web；无 form 能力、仅 URL 能力、宿主表单失败或旧运行时自动返回审阅链接。

私有运行时准备十分钟有效的一次性票据，宿主接受才提交；取消/拒绝/过期/无效答案不写业务数据。提交校验修订、快照、候选版本、覆盖版本和指纹，授权还比较原策略版本。已接受事件保存 mcp_elicitation 来源、批次与指纹；表单摘要和提交输出均经过资料过滤及发送审计。单位仍无猜测默认值，采用依据必填。

验证：54 项 Node 测试、13 项 Python 几何测试、TypeScript 与生产构建通过；发行包构建、安装与 ZIP 校验通过。外部安装目录只读验收发现 37 个工具，导入、计算、覆盖小计、导出、审阅资源及断开存活通过。真实 Codex CLI 0.165.0 验证 mcpServer/tool/call → mcpServer/elicitation/request → cancel 转发链路，未发模型任务，使用受控临时图纸与模拟 App 客户端取消。证据见 docs/evidence/session-review-host-probe.json，桌面实际表单视觉仍待用户会话验证；不将模拟客户端测试称为真实用户确认。

本机 bwc-workspace@bwc-local 更新至 0.4.0；当前工程确认没有 queued/running 任务后，平滑停止旧运行时并从新安装包启动。未代用户采用真实图纸单位或确认候选。会话需重新连接插件以发现新工具，旧审阅链接需重新打开。
