## 数值与状态验证

`npm run check` 包含 13 项 Node 集成/协议测试和 9 项 Python 几何测试；生产 TypeScript 检查与构建通过。测试验证：

- 6×4m 外轮廓、1m² 内部洞口：23m² × 0.15m = 3.45m³；改 0.20m 后 4.60m³。
- 固定 `150mm` 厚度在源比例从 1 变为 0.001 后仍为 0.15m，体积变为 0.00000345m³；源几何厚度则按 s³ 缩放，历史结果保留原单位。
- 自交、开口、非共面、洞口外越/接触/重叠/重复扣减被拒绝；缺厚度或单位时 item.value=null、completeTotal=null。
- 倾斜共面面积、变换椭圆面积、大坐标、OCS 圆心/高程、嵌套非零基点、镜像与缩放；MINSERT 的 2×3 和 3×4 样本检查行列位置和完整路径，单成员图元编辑明确拒绝。
- 原生移动后对象身份保持；查询/预览和计量引用新快照，撤销前滚；冻结分页、跨项目隔离、旧选择拒绝、过期候选 CAS 拒绝和重复 operationId 去重。
- 重启恢复结果/对象/选择、事件补读；模拟真实领域变更已提交但宿主回执丢失，重复消息不再写入，先对账；停止 Agent 不取消领域任务。
- 受控候选 DWG 不修改另存程序指纹通过；独立 CAD 仍为 not_run，完整交付为 false。该状态没有被测试强行改为通过。

真实宿主测试见 [host-bridge-smoke.json](evidence/host-bridge-smoke.json)：Codex 经 MCP 读取图纸，再按已持久化用户消息生成候选、应用 150mm 厚度并从几何工具得到 3.45m³。该测试使用宿主模型，而非模拟回复。故障恢复/回执丢失测试使用可控协议替身，同时执行真实领域事务；不能据此称当前宿主所有历史恢复接口已验收。

浏览器实际执行了建项目、导入受控 DWG、采用米制、关联洞口、修改厚度、计量和导出 CSV；截图：[受控计算](evidence/workbench-controlled.png)、[真实附房建筑预览](evidence/workbench-real-building.png)、[工作台自然语言修改后 4.60m³](evidence/workbench-ai-result.png)。实际页面从消息提交到工具变更/计量的检查记录见 [browser-acceptance.json](evidence/browser-acceptance.json)。真实附房建筑的已支持部分显示在二维画布，导入缺口持续展示，不将这张画面作为独立 CAD 外观参考。

## 真实样本与后端决策

完整数据见 [sample-probe.json](evidence/sample-probe.json) 和 [样本解析实测](evidence/样本解析实测.md)。七份文件均成功产生规范索引，但七份均为 partial。建筑/结构 `_t3` 文件分别有 16,316 / 19,930 条模型实体，电气为 32,265 条，给排水为 25,933 条；不能统称为四份 T3。

不改另存程序探测：建筑、电气、原单体及总图四份因 ACadSharp 重复 key 报错；结构、给排水、厂房及受控文件支持状态指纹相等。**后四者的相等仅覆盖已提取支持状态**，不证明未知对象载荷、专业语义或全部文档属性保持。七份真实文件均不开放完整重写交付。后续必须修复并复验后端，或在具备合法环境与样本后替换适配器；不能用项目参数覆盖层替代这个门槛。

原生专业对象的可编辑性、T3 转换完整性和业务构件确认仍需提供方资料及独立 CAD 环境。登记转换记录会绑定原/副本指纹、软件版本、选项和证据；当前不会自行标为 verified。同一个项目修订只采用一个图纸版本，不将原图/副本叠加算量；跨解析版本的业务引用需要重新确认。

## 已固定契约与剩余工程

坐标契约为 `bwc-wcs-1`：规范曲线存源 WCS 双精度；矩阵为行序列化、列向量、从内到外组合；单位最后解释；显示居中不写回。曲线计算使用规范线段/参数弧，面积用 Green 积分，Shapely 负责按 1e-5m 拓扑容差核验，不从画面离散点计算工程量。

操作 schema 在 `server/schemas.ts`；模型侧 MCP 用不含 draft-07 tuple 的兼容表达，执行时仍由服务端严格 schema 校验。候选只绑定已有用户意图，执行时比较基础修订和候选指纹；新快照发布后旧结果失效。仅身份保持编辑进入可用能力表，不伪造拆分/合并谱系。

Codex 协议按官方 [App Server](https://learn.chatgpt.com/docs/app-server) 接入，MCP 权限只在本应用生成的 `bwc` 配置中设置，不改全局配置。实测 `thread/read(includeTurns=true)` 返回 `list_turns is not supported yet`，因此该路径目前返回 recovery_required，禁止自动重发。Claude Code 2.1.311 只完成 CLI 形态盘点，未完成方案要求的双宿主行为比较，P0 不能标为全部完成。

下一步顺序：解决真实样本往返后端与独立 CAD 环境 → 原生/T3 配对及任务语义 → 递归依赖重写/迁移 → 宿主完整恢复与 Claude 比较 → 扩大图元编辑/拓扑/三维 → 目标设备性能及安装分发。当前软件保留这些缺口，不修改方案的必需交付定义。
